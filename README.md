# 財表暗記ノート

財務諸表論 理論暗記アプリ

## ディレクトリ構成

```
zaihyo/
├── index.html              ← アプリ本体（単一HTMLファイル）
├── data/
│   ├── manifest.json       ← 読み込む単元の一覧
│   ├── dento-01.json       ← 単元データ（財務会計総論Ⅰ-1）
│   ├── dento-02.json       ← 単元データを追加していく
│   └── ...
└── README.md
```

## デプロイ方法

GitHub Pagesで公開する場合、リポジトリの `zaihyo/` ディレクトリをそのまま配置するだけ。
公開URL例：`https://miyuyo.github.io/zaihyo/`

ローカルで動作確認する場合：
- **HTTPサーバー経由**（推奨）：例えば VS Code の Live Server 拡張、または `python3 -m http.server` でローカルサーバーを立ち上げる
- **ファイル直接ダブルクリック**：fetchが効かないので、内蔵デフォルトデータのみ表示される（dento-01のみ）

## 単元データを追加する手順

### 1. スタディングのPDFをClaude に渡す

新しいチャットで以下のように依頼：

> 財表暗記ノートのアプリに追加する単元データを作ってください。
> 添付したスタディングPDFを元に、以下のJSON形式で出力してください。
> ・unit_id, unit_name, category, cards 構造
> ・カードごとに id, section, topic, importance, question, answer_full, keywords, related, pair_group
> ・keywords はスタディングの穴埋め範囲（四角枠）に正確に揃える
> ・importance は推測で A/B を設定（後でアプリ内で変更可能）
> ・related は同じ単元内の対比・セット・派生・対応の関係をリンク

複数単元のPDFをまとめてアップロードしてOK。

### 2. 出力されたJSONを保存

`data/dento-02.json` のようなファイル名で `data/` フォルダに保存。

### 3. manifest.json に追記

```json
{
  "version": 1,
  "title": "財表暗記ノート 教材データ",
  "units": [
    "dento-01.json",
    "dento-02.json"
  ]
}
```

### 4. アプリをリロード

ブラウザでリロードすると新しい単元が自動で読み込まれる。

## カードデータの構造

```json
{
  "unit_id": "dento-02",
  "unit_name": "財務会計総論Ⅰ-2",
  "category": "伝統理論編",
  "cards": [
    {
      "id": "d02-01-01",
      "section": "1.セクション名",
      "topic": "カード題名",
      "importance": "A",
      "question": "問題文",
      "answer_full": "完全な解答文",
      "keywords": ["スタディングの", "穴埋め箇所と", "完全一致させる"],
      "related": [
        {"id": "d02-01-02", "type": "対比", "note": "対のカード"}
      ],
      "pair_group": "セットで覚えるグループ名"
    }
  ]
}
```

### 命名規則

- `unit_id`：単元の一意ID（例：`dento-01`、`gaihen-01`）
- `id`：カードのID。`{単元略号}{セクション番号}-{連番}` 形式が推奨（例：`d01-03-04`）

### importance の基準（初期値）

| ランク | 該当 |
|-------|------|
| A | 用語の基本定義、対比構造の核、本試験で頻出と推測される論点 |
| B | 派生・補足、具体例、周辺事項 |
| C | （余力があれば。試験には出にくいと判断したもの） |

※アプリ内で個別に変更可能。

### related の type

| type | 意味 | 線色（関連マップ） |
|------|------|------------------|
| 対比 | 2つを比較して覚える（例：資本主理論 ⇔ 企業主体理論） | 赤 |
| セット | 一緒に覚える（例：会計公準3点セット） | 金 |
| 対応 | 横の対応関係（例：機能2つ → 利益の特質2つ） | 図には未表示（データには保持） |
| 派生 | 派生関係・具体例（例：継続企業の公準 → 減価償却） | 図には未表示 |

## 学習データのバックアップ

設定画面の「書出/取込」から、SRS履歴・重要度の変更・設定値をJSONで書き出し / 読み込みできる。
端末を切り替えるとき（PC ⇔ iPad ⇔ スマホ）に使う。
